## 0. Rules

- [DECISION] Этот реестр фиксирует только технологии/системы, которые *уже подразумеваются* действующими SSOT/BASELINE.
- [DECISION] Реестр не является baseline: он не задаёт “как выглядит”, а только “что существует/используется”.
- [DECISION] Любые спорные/неопределённые технологии выносить в REG-UNKNOWN, а сюда добавлять только после фиксации в SSOT/BASELINE.

## 1. Registry schema

- [DECISION] Поля записи:
  - `tech_id` — стабильный идентификатор (`TECH-2215-xxxx`)
  - `name` — короткое имя
  - `domain` — область (energy, infra, housing, city, transport, health, compute, manufacturing, security, interface)
  - `availability` — где это норма (LEVEL-MID / LEVEL-LOW / LEVEL-HIGH / global)
  - `what_it_enables` — какие baseline/scene-ожидания это обеспечивает
  - `notes` — ограничения/границы применения
