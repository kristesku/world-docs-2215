## 0) Reader Contract

Назначение: документ используется напрямую при написании сцен.

Правило дефолта: если параметр среды не указан явно в сцене —
применяется DEFAULT из этого документа.

Запрет на домысливание: запрещено добавлять “логичные” детали вне
DEFAULT / FACT / INFERENCE.

При конфликте приоритет имеет SSOT (WORLD-DOC-*).

Любые отклонения допускаются только если они RETCON-совместимы.

## 1) Access Levels (нормы среды)

NOTE: уровни не являются социальной иерархией, а отражают доступ к
среде.

LEVEL-MID является дефолтом для романа.

### LEVEL-LOW (ограниченный доступ)

- Неполный климат-контроль

- Повышенный фоновый шум

- Частично ручное обслуживание

- Ограниченная связность

- Упрощённые интерфейсы

### LEVEL-MID (служебный / профессиональный) — DEFAULT

- Полный климат-контроль

- Акустическая изоляция

- Скрытые интерфейсы

- Автономное обслуживание

- Постоянная связность

### LEVEL-HIGH (расширенный доступ)

- Индивидуальные режимы среды

- Почти полная тишина

- Персонализированные интерфейсы

- Предиктивное обслуживание

- Приоритетные сети

- Энергия не упоминается?
